# EliteHomes - Real Estate Landing Page

Bootstrap exam: a landing page for a real estate company, built to match the given design as closely as possible on desktop, tablet and mobile.

## Built with

- HTML
- Bootstrap 5.3 (grid, utilities, navbar collapse, dropdown, tabs, carousel, collapse/accordion, scrollspy)
- Custom CSS for what Bootstrap doesn't cover (gradients, transitions, transforms, `::before` / `::after`, hover effects)
- Font Awesome 6 for the icons
- A tiny bit of JavaScript (closing the mobile menu after picking a link). Everything else interactive is Bootstrap's own JS.

## Sections

1. Fixed navbar with a "Properties" mega menu (desktop) and a collapsible menu (mobile)
2. Hero with a property search form and quick stats
3. Featured properties cards
4. Services tabs (Buying, Selling, Renting, Investing, Commercial)
5. Testimonials carousel
6. FAQ accordion
7. Contact cards, contact info, social links and a contact form
8. Footer

## Run it

No build step. Just open `index.html` in a browser (it needs internet for the Bootstrap, Font Awesome and Unsplash CDNs).
